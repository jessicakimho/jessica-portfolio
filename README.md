# Jessica's Portfolio

My personal portfolio as a software engineer, featuring my experience, projects, resume, and a way to get in touch. An interactive koi pond brings a little calm to the page.

## Built with

- **HTML, CSS, and JavaScript** for the page and interactions.
- **Koi Pond Kit** with WebGL2 and Canvas 2D for the animated pond.
- **React, TypeScript, and Tailwind CSS** for the project carousel, adapted from Originkit's Coverflow Gallery.
- **Vite** for development and production builds.
- **Formspree** for the contact form.

## Run locally

```sh
npm install
npm run dev
```

Run `npm run build` to create the production site in `dist/`.
